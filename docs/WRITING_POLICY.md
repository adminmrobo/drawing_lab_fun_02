## 1. 목적과 독자
| 항목 | 방침 |
|---|---|
| 목적 | 같은 캐릭터를 여러 그림체(시대·선과 지역·흑백·등신·표정·매체와 옷)로 **다양하고 즐겁게** 바꿔 그리며, 무엇을 바꾸고 무엇을 남겨야 같은 캐릭터로 보이는지 실험으로 익힌다. AI에게 그림체를 작품 이름 없이 특징으로 요청하는 문장까지 만든다 |
| 독자 | 그림·AI를 처음 접하는 비전공자 |
| 원리 먼저 | "고정값은 붙잡고, 축 하나를 돌린다"로 모든 베리에이션을 설명한다 |
| 스킬 | `ai-lab-explainer-plain`(원리 먼저 교수법 P1~P7) — drawing_lab_03과 같은 틀 |
| 콘셉트 | 베리에이션(variation). 참고 그림을 **비지도학습처럼** 비슷한 것끼리 넓게 묶어 군집을 만들고, 군집 하나를 부 하나로 삼는다. 그림마다 정답 하나만 붙이지 않고(원-핫처럼 하나씩 나누지 않고) 경계에 걸친 그림은 걸친 대로 둔다 |

## 2. 원자료와 저작권
1. 출발점은 사용자가 모아 준 참고 그림 70여 장(애니·만화 장면, 밈, 팬아트, AI 그림, 서양·일본 화풍 분류표 2장, 흑백 러프·나이 비교 시트)이다. **그림은 싣지 않고, 작품·캐릭터 이름도 적지 않는다.** 그림마다 '무엇이 바뀌었나'만 여섯 특징(시대·선·사실·과장·재료·색)으로 옮겨 `build/style_points.py`에 60개 점으로 정리했다(비슷한 그림은 한 점으로 묶음).
2. 작가가 'AI 학습·사용 금지'를 밝힌 그림은 그림 요청에 첨부하지 않고 구도만 말로 참고한다.
3. 원리 출처: k-평균(MacQueen 1967), 주성분(Pearson 1901), 단순화 축(McCloud 1993), 과장·움직임(Thomas·Johnston 1981), 회색값(ITU-R BT.601), 확산 모델(Rombach 2022). 책의 그림·문장·구성은 옮기지 않는다.
4. 모든 숫자(특징 점수, 색 수, 굵기 비, 망점 비율, 등신, 잔상 간격, 회색값 차이 40, 일관성 점수, 판정 거리 0.25 등)는 예시값이라고 본문·바닥글에 밝힌다.

## 4. 등장인물·안전
- 모든 인물은 성인(하루·시아·모아 20대, 박사 30대 남성). **SD는 그림체일 뿐 나이가 아니다** — 프롬프트마다 'adult … not a child'를 넣는다.
- 고정값: 하루(분홍 머리 + 남색 줄, 번 2개, 앞머리 가운데 남색 줄, 라벤더 후드) / 시아(검은 생머리, 장식 없음, 은 귀걸이) / 모아(웨이브, 흰 프릴 머리띠, **왼쪽** 귀 위 리본) / 박사(흰 줄 짙은 머리, 굵은 눈썹, 청록 사각 안경).
- 나이 신호(7부): 어린이 = 낮은 눈 높이·크고 둥근 눈·짧은 코 / 성인 = 가로로 긴 눈·또렷한 코. SD·큰 눈을 쓸 때 성인 신호 하나 이상과 나이 문장을 함께 넣는다.
- 웃음의 대상은 상황과 반응. 생김새·집단·실존 인물은 웃음의 대상으로 삼지 않는다(f7). 교복 느낌·노출 금지.

## 5~8. 페이지·단계·문장·직접 만들기
drawing_lab_03 방침과 같다: 픽셀 표지 → 세 줄 요약 → 오늘의 과제 → 단계 4 → 직접 만들어 보기 A·B(부마다 2개) → 연습 과제(부마다 1개) → 평가 → 정리 → 다음으로 → 색인·꾸러미. 수식 상자는 말로 하면 → 숫자 3줄 → 학교 수학 → 식. 금지어(칸·사다리·관통, 독자를 수학·통계를 포기한 사람으로 부르는 줄임말) 0건.
