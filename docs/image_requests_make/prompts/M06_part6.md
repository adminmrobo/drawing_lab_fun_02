# M06 · 6부 '직접 만들어 보기' 비교 그림

**Genspark에 먼저 붙여 넣기 ↓**
```
해설 페이지의 '직접 만들어 보기' 비교 그림을 만들어 줘.
- 첨부한 그림(이미 만든 A 결과)과 똑같은 캐릭터·구도·빛을 유지하고, 아래 'Change only'에 적힌 것만 바꿀 것
- 비율은 첨부한 A 결과와 같게
- 등장인물은 모두 20대 성인(박사는 30대 성인 남성). 노출·교복 느낌·어려 보이는 얼굴 금지
- 그림 안에 글자·숫자·글씨·도장·로고 금지
```
