```
해설 페이지의 '직접 만들어 보기' 비교 그림을 만들어 줘.
- 첨부한 그림(이미 만든 A 결과)과 똑같은 캐릭터·구도·빛을 유지하고, 아래 'Change only'에 적힌 것만 바꿀 것

```
